# VirtuFit Studio – Virtual Dress Try-On Experience

Responsive virtual fitting room website built with React, Vite, React Router, Bootstrap, and custom styling. The experience highlights immersive try-ons, curated lookbooks, pricing tiers, and a contact hub for fashion brands ready to launch digital fitting rooms.

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to browse the experience.

## Available Pages

- Home – hero, product value, and call-to-action banner
- Virtual Fitting – workflow overview and capabilities
- Gallery – licensing-safe imagery sourced from Pexels
- Pricing – three-tier subscription options
- Contact – inquiry form and support details

## Production Build

```bash
npm run build
```

The compiled assets will be output to the `dist` directory, ready for deployment on Vercel or any static hosting provider.
